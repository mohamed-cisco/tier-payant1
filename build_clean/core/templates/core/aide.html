📖 Guide utilisateur

Plateforme Tiers Payant — Djazair Med

🎯 Bienvenue

Ce guide vous accompagne dans l'utilisation de la plateforme Tiers Payant. Chaque section est accessible via le menu de gauche. Pour toute question, contactez votre administrateur.

1️⃣ Présentation générale

🎯 Objectif de la plateforme

La plateforme Tiers Payant permet de gérer :

  • Les adhérents et leurs ayants droit
  • Les contrats avec les souscripteurs
  • Les prestataires de santé
  • Les demandes de prise en charge
  • Les factures et règlements
  • Les recours et l'audit
🔐
Sécurité : chaque utilisateur dispose d'un nom utilisateur unique, d'un mot de passe personnel, et de rôles qui déterminent ses permissions. Ne partagez jamais votre mot de passe.

2️⃣ Connexion et déconnexion

🚪 Se connecter

  1. Ouvrez votre navigateur (Chrome, Edge, Firefox)
  2. Saisissez l'adresse de la plateforme
  3. Entrez votre nom utilisateur et mot de passe
  4. Cliquez sur 🔐 Se connecter

🚪 Se déconnecter

Cliquez sur 🚪 Déconnexion en bas du menu latéral.

⚠️
Important : déconnectez-vous toujours avant de quitter votre poste, surtout sur un ordinateur partagé.

3️⃣ Tableau de bord

Le tableau de bord offre une vue d'ensemble de votre activité :

📊 Cartes statistiques

  • 👥 Nombre d'adhérents
  • 📄 Contrats actifs
  • 📝 Demandes en attente
  • 💰 Factures en attente

📈 Graphiques

4️⃣ Module Adhérents

👥 Créer un adhérent

  1. Menu Adhérents → bouton ➕ Nouvel adhérent
  2. Remplissez les informations (Nom et Prénom sont obligatoires)
  3. Cliquez 💾 Enregistrer
✅
Le numéro d'adhérent est généré automatiquement au format ADH-2026-0001.

👨‍👩‍👧 Ajouter un ayant droit

  1. Ouvrez la fiche adhérent → Détails
  2. Section Ayants droit → + Ajouter un ayant droit
  3. Remplissez :
    • Nom (auto-rempli pour les enfants)
    • Prénom, date de naissance, sexe
    • Type de lien : Conjoint(e), Enfant, Parent, Autre
  4. Cliquez 💾 Enregistrer

🎫 Carte adhérent PDF

Sur la fiche adhérent, cliquez sur 🎫 Carte adhérent.

Le PDF contient :

  • Infos du titulaire
  • Section Ayants droit
  • Zone de signature

📥 Import Excel

Colonnes attendues dans le fichier :

nom | prenom | date_naissance | sexe | adresse | telephone | email | date_adhesion

5️⃣ Contrats et Garanties

🏢 Créer un souscripteur

Menu Souscripteurs → ➕ Nouveau souscripteur.

📄 Créer un contrat

  1. Contrats → ➕ Nouveau contrat
  2. Sélectionnez le Souscripteur
  3. Remplissez dates, type, objet
ℹ️
Toutes les garanties actives sont automatiquement liées au nouveau contrat.

🛡️ Garanties et Actes

Menu Garantie ↔ Acte → + Associer un acte

  • Sélectionnez la garantie + l'acte
  • Taux de prise en charge (%)
  • Franchise (DA)

💰 Plafonds

Menu Plafonds → ➕ Nouveau plafond

TypePériodeNiveau
MontantJourAdhérent
QuantitéMoisPersonne
MixteTrimestre / Semestre / AnnéeContrat

6️⃣ Prestataires et Conventions

🏥 Créer un prestataire

Prestataires → ➕ Nouveau prestataire

Types disponibles : Pharmacie, Médecin, Clinique, Laboratoire, Centre de radiologie, Dentaire, Optique, Autre.

🤝 Créer une convention

Conventions → ➕ Nouvelle convention

⚠️
Sans convention active, aucune demande TP ne peut être créée pour ce prestataire.

7️⃣ Demandes de Tiers Payant

📝 Créer une demande TP

  1. Demandes TP → ➕ Nouvelle demande
  2. Sélectionnez : bénéficiaire, contrat, prestataire (avec convention active)
  3. Enregistrez — la demande est créée en EN_ATTENTE

➕ Ajouter des actes

Workflow en cascade :

1
Choisissez l'Acte → la page recharge
↓
2
Choisissez le Sous-acte → la page recharge
↓
3
Choisissez le Prestataire → le tarif se charge
↓
4
Saisissez la Quantité puis enregistrez

✅ Valider une demande

  1. Bouton ✓ Valider la demande
  2. Vérifiez les calculs (taux, franchise, plafonds)
  3. Cliquez ✓ Valider et créer la PEC
✅
Une Prise En Charge (PEC) est créée avec un numéro PEC-2026-XXXX. Générez son PDF pour le prestataire.

8️⃣ PEC et Consommations

🏥 Prises en charge

  • Liste complète sur Prises en charge
  • Détails → voir les actes pris en charge
  • 📄 Télécharger PDF → document officiel
⏰
La PEC a une date d'expiration (30 jours par défaut). Passée cette date, elle n'est plus valide.

🧾 Créer une consommation

  1. Sur la fiche PEC → Créer une consommation
  2. Saisissez :
    • Sous-acte
    • Date de prestation
    • Quantité
  3. Le tarif se charge automatiquement

✅ Valider / ❌ Annuler

Sur la fiche consommation :

  • Valider → peut être facturée
  • Annuler → peut être recréée

9️⃣ Facturation et Règlements

💰 Créer une facture

  1. Factures → ➕ Nouvelle facture
  2. Sélectionnez le Prestataire
  3. La facture regroupe automatiquement toutes les consommations validées non facturées

📄 Exports disponibles

  • 📊 Exporter Excel → liste complète
  • 📄 Exporter PDF → liste en PDF
  • Sur la fiche facture → 📄 Télécharger PDF → facture détaillée

💳 Créer un règlement

  1. Règlements → ➕ Nouveau règlement
  2. Sélectionnez une facture VALIDEE ou PARTIELLEMENT_PAYEE
  3. Saisissez date, montant, mode (Virement / Chèque / Espèces)

✅ Valider un règlement

Le statut de la facture est mis à jour automatiquement :

  • PAYEE si le total réglé ≥ montant validé
  • PARTIELLEMENT_PAYEE sinon

🔟 Recours

⚖️ Créer un recours

Recours → ➕ Nouveau recours

  • Personne concernée
  • Type : Médical / Facturation / Administratif
  • Date, objet, motif

🎯 Traiter un recours

  1. Bouton Traiter
  2. Décision :
    • Type : Acceptée / Rejetée / Acceptée partiellement
    • Motif
    • Montant accordé

1️⃣1️⃣ Administration

👤 Créer un utilisateur

  1. Utilisateurs → + Nouvel utilisateur

  1. Rôles → + Nouveau rôle
  2. Sur la ligne du rôle → Permissions
  3. Cochez les permissions par module
  4. Enregistrer les permissions

1️⃣3️⃣ FAQ et dépannage

❓ Questions fréquentes

J'ai oublié mon mot de passe

Contactez l'administrateur pour qu'il le réinitialise.

Je ne vois pas certains menus

Vous n'avez pas les permissions nécessaires. Contactez l'administrateur.

« Aucune convention active avec ce prestataire »

Créez une convention pour ce prestataire, à la date d'aujourd'hui.

« Aucun tarif actif pour ce sous-acte »

Créez un tarif pour ce sous-acte + prestataire + date.

Le calcul de la PEC donne 0 DA

Vérifiez que la garantie-acte a bien un taux > 0 et que le plafond n'est pas épuisé.

La carte adhérent ne contient pas les ayants droit

Vérifiez que leurs statuts sont ACTIF et qu'ils sont bien rattachés à cet adhérent.
